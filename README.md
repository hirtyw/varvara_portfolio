# Портфолио Варвары Кокиной

Первые пять блоков по Figma: версии 1920, 1440, 1200 и 393 px.

## Запуск

Нужен Node.js 20.11 или новее. Установка зависимостей не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173. Для сравнения с макетом установить ширину viewport 1920 CSS px и масштаб браузера 100%.

## Публикация на Vercel

`npm run build` формирует папку `dist/` с файлами сайта и ресурсами. `vercel.json` задаёт статическую публикацию этой папки. Локальный `server.mjs` на хостинге не используется.

## Файлы проекта

- `index.html` — семантическая разметка страницы.
- `design-system.css` — общие цвета, локальные шрифты, шкалы размеров и отступов, сетка и адаптивные значения.
- `styles.css` — стили компонентов и индивидуальное кадрирование изображений.
- `assets/` — оригинальные изображения Figma и локальные начертания Geist 400/500.
- `server.mjs` — локальный сервер без зависимостей.
- `navigation.js` — мобильное меню, закрытие по Esc и при переходе на десктоп.
- `clients.js` — подготовка бесконечной мобильной ленты логотипов.
- `reveal.js` — однократное появление блоков при прокрутке через IntersectionObserver.
- `projects.js` — круглый курсор над превью проектов, пока с подписью «Скоро».

## Система оформления

Все общие настройки находятся в `design-system.css`, который подключён перед стилями компонентов и включён в сборку. Изменение переменной применяется ко всем использующим её элементам.

- Цвета: `--color-text` — основной текст и иконки меню, `--color-muted` — второстепенный текст, `--color-heading-muted` — светлый текст, `--color-divider` — разделители, `--color-background` — фон страницы и шторок появления.
- Типографика: `--text-*` задают шкалу, `--heading-size`, `--body-size`, `--label-size` и другие роли связывают её с компонентами.
- Отступы: шкала `--space-*` основана на 4 px; `--space-4` = 16 px, `--space-10` = 40 px. `--section-space` задаёт общие вертикальные отступы секций.
- Сетка: `--container-width` и `--page-gutter` управляют шириной страницы; `--grid-content-start` выравнивает правые колонки разделов.
- Анимации: `--motion-*-duration` и `--motion-*-easing` задают длительность и плавность появления.

Адаптивные значения собраны ниже в том же файле. Например, размер заголовков меняется с `--text-heading` на `--text-heading-mobile` в мобильном брейкпоинте. Чтобы изменить мобильное значение, редактируйте соответствующее переопределение. Особые размеры композиции из Figma сохранены отдельно от общей шкалы; кадрирование фотографий и пропорции логотипов остаются в компонентах.

Изменения проверяем локально. Коммиты, отправка в GitHub и публикация на Vercel выполняются только по прямой команде пользователя.

Реализован первый экран с адаптивами. На десктопе центральный блок имеет ширину 709 px, шапка меняется по макетам 1920/1440/1200. До 767 px включительно используется мобильная компоновка с меню, заголовком 40 px (плавно уменьшается на узких экранах) и характеристиками в две колонки. На 393 px высота секции — 830 px.

Десктоп использует пользовательский `head1.jpg` без скруглений, мобильная версия — полное изображение `hero-project.png` с кадрированием из мобильного макета.

CV скачивает файл `assets/documents/Кокина_Варвара_CV.pdf`. Ссылка «Работы» ведёт к секции `#projects`. «Связаться» открывает почту из макета. Тексты сохранены как в Figma.

Блок «Работала с» содержит восемь оригинальных SVG-логотипов в `assets/images/clients/`. На десктопе используется сетка в два ряда, на мобильном — плавная бесконечная лента со скоростью 32 px/с. CSS выполняет анимацию; JavaScript добавляет одну копию последовательности для бесшовного стыка и скрывает её от скринридеров. При переходе на десктоп копия удаляется. При касании, наведении или фокусе лента приостанавливается. При `prefers-reduced-motion: reduce` доступна ручная прокрутка без автодвижения. Лента не расширяет страницу. Размеры и порядок соответствуют макетам.

Блок «Обо мне» построен на CSS Grid: фото и текст расположены рядом на десктопе, последовательно на мобильном. Фотография сохранена в `assets/images/about-portrait.png`. Срок опыта унифицирован с первым экраном и макетом 1920 px — более 5 лет.

Блок «Некоторые работы» содержит девять карточек. На десктопе описание и превью расположены рядом, теги поверх изображения. На мобильном описание, изображение и теги идут последовательно. Оригиналы превью хранятся в `assets/images/projects/`; первый проект повторно использует `hero-project.png`. Для составных браузерных превью экспортирован только иллюстративный контент, разметка секции и теги остаются HTML. Кадрирование соответствует каждой версии макета. Переходы к отдельным кейсам пока не подключены: внутренние страницы ещё не готовы.

Блок «Опыт работы» (`#experience`) содержит пять мест работы с должностями и датами. Компоновка на CSS Grid адаптируется без дублирования контента; даты размечены элементами `time`.

Анимации появления ориентированы на romemichal.pl: проявление текста за 1 секунду и открытие изображений вертикальной шторкой за 0,9 секунды. Эффекты запускаются один раз при входе в экран; небольшие задержки задают последовательность. Сторонние библиотеки не используются. При `prefers-reduced-motion: reduce`, без JavaScript и при печати содержимое доступно без эффектов. Анимации не меняют размеры и расположение блоков.

Наведение на кейсы повторяет поведение референса: превью увеличивается на 4% за 0,7 секунды, заголовок подчёркивается, теги появляются с шагом 50 мс, остальные кейсы приглушаются до 40% непрозрачности. Над изображением появляется оранжевый круг «Скоро», поскольку страницы кейсов ещё не подключены. Параметры находятся в `design-system.css`. Эффекты включены для точного указателя с поддержкой наведения и отключены при `prefers-reduced-motion: reduce`; на сенсорных устройствах теги видимы постоянно. Размеры карточек при наведении сохраняются.
