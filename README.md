# Портфолио Варвары Кокиной

Первые три блока по Figma: версии 1920, 1440, 1200 и 393 px.

## Запуск

Нужен Node.js 20.11 или новее. Установка зависимостей не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173. Для сравнения с макетом установить ширину viewport 1920 CSS px и масштаб браузера 100%.

## Публикация на Vercel

`npm run build` формирует папку `dist/` с файлами сайта и ресурсами. `vercel.json` задаёт статическую публикацию этой папки. Локальный `server.mjs` на хостинге не используется.

## Файлы проекта

- `index.html` — семантическая разметка шапки и первого экрана.
- `styles.css` — локальные шрифты, переменные и стили компонентов. Основная компоновка использует обычный поток и flex; абсолютное позиционирование нужно только для кадрирования аватара из Figma.
- `assets/` — оригинальные изображения Figma и локальные начертания Geist 400/500.
- `server.mjs` — локальный сервер без зависимостей.
- `navigation.js` — мобильное меню, закрытие по Esc и при переходе на десктоп.
- `clients.js` — подготовка бесконечной мобильной ленты логотипов.

Реализован первый экран с адаптивами. На десктопе центральный блок имеет ширину 709 px, шапка меняется по макетам 1920/1440/1200. До 767 px включительно используется мобильная компоновка с меню, заголовком 40 px (плавно уменьшается на узких экранах) и характеристиками в две колонки. На 393 px высота секции — 830 px.

Десктоп использует пользовательский `head1.jpg` без скруглений, мобильная версия — полное изображение `hero-project.png` с кадрированием из мобильного макета.

CV скачивает файл `assets/documents/Кокина_Варвара_CV.pdf`. Кнопка «Работы» временно отключена до добавления секции проектов. «Связаться» открывает почту из макета. Тексты сохранены как в Figma.

Блок «Работала с» содержит восемь оригинальных SVG-логотипов в `assets/images/clients/`. На десктопе используется сетка в два ряда, на мобильном — плавная бесконечная лента со скоростью 32 px/с. CSS выполняет анимацию; JavaScript добавляет одну копию последовательности для бесшовного стыка и скрывает её от скринридеров. При переходе на десктоп копия удаляется. При касании, наведении или фокусе лента приостанавливается. При `prefers-reduced-motion: reduce` доступна ручная прокрутка без автодвижения. Лента не расширяет страницу. Размеры и порядок соответствуют макетам.

Блок «Обо мне» построен на CSS Grid: фото и текст расположены рядом на десктопе, последовательно на мобильном. Фотография сохранена в `assets/images/about-portrait.png`. Срок опыта унифицирован с первым экраном и макетом 1920 px — более 5 лет.
